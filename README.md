# machine-learning-projects-portfolio

***
## 📚 Домашние задания по курсу машинного обучения
Этот репозиторий содержит мои домашние задания, выполненные в рамках курса по машинному обучению.

### 📁 Структура репозитория
Каждое домашнее задание представлено отдельным файлом, имя которого отражает его номер и основную тему. Большинство заданий выполнено в формате **Jupyter Notebook (.ipynb)**, что обеспечивает удобство просмотра кода, комментариев и результатов выполнения.

- `Домашняя_работа_№X_Название_темы.ipynb`: Файл с домашним заданием.
- `Домашняя_работа_№11_Оценка стоимости проекта и ТЗ.rar`: Архив с дополнительными материалами.
